# Calculator

A simple calculator built with HTML, CSS and JavaScript.

## What it does

- Add, subtract, multiply and divide
- Clear the display
- Delete the last digit

## How to run

Open index.html in your browser. That is it.

## Files

- index.html
- style.css
- calculator.js

## Why I built this

To refresh my memory on JavaScript DOM manipulation and event handling and the logic behind it without the help of AI
